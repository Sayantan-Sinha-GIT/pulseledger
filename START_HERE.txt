RUN LOCALLY
Install Node.js 24. A Cloudflare account is not required for local use.
From this folder:
  npm ci
  npm run setup:local
  npm run db:reset:local
  npm run dev
Open http://127.0.0.1:8787/ and /admin.
Read the generated local password in secrets/owner-credentials.txt.
setup:local never overwrites an existing .dev.vars configuration.
If restoring this exact deployment, use the RECOVERY files instead
of generating a new owner password. Local checks can be triggered at:
http://127.0.0.1:8787/cdn-cgi/local/scheduled

REDEPLOY
Use your Cloudflare Wrangler login. For this existing deployment, preserve
the current database ID in wrangler.jsonc and existing Worker secret.
For a different account, create a new D1 database and update that ID.
  npm run db:migrate:remote
  npm run deploy
The Worker, D1 database, and password secret live on Cloudflare. RECOVERY has
a dated database export. It does not include your Cloudflare account login.

WHAT IT MONITORS
11 public URLs across Haan, StyleShopZ, CodeSense, Grepless, ArthaSetu and
Dispatch. The owner desk can manage up to 12 monitors and incidents.
Scheduled checks run every 15 minutes. Public refresh reads one persisted
snapshot instead of scanning history. Incidents show severity, actual
lifecycle status, affected service, timestamped updates and resolution.
This is HTTP endpoint monitoring, not a test of those apps' private flows.
Single owner; no email/SMS alerting or team access. These are stated scope
limits, not hidden unfinished features. No Android APK is needed for this
web-only product.
